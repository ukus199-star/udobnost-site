# Как посмотреть статистику теста

## Одной командой

Из корня рабочей папки:

```
bash scripts/stats.sh
```

Выключите VPN перед запуском: Amvera не пускает подключения с зарубежных
адресов.

Что покажет:

```
СТАТИСТИКА ТЕСТА «НАСКОЛЬКО ВЫ УДОБНЫ»

Прохождений начато:             7
Дошли до результата:            4
Доходит до конца:               57%

Где бросают тест:
   вопрос 5 - ушли 2
   вопрос 9 - ушли 1

Какие типы выпадают:
   Спасатель: 2
   Отличница: 1
   С границами в порядке: 1

Всего записей в базе:           61
Первая:                         09.09.2026, 18:44:08
Последняя:                      11.09.2026, 14:02:31
```

## Первый раз: создать файл со строкой подключения

Файл `udobnost/.env.local`. В репозиторий он не попадает - в `.gitignore`
записано, что всё начинающееся на `.env` туда не идёт.

Одна строка:

```
DATABASE_URL=postgres://teststatsuser:ПАРОЛЬ@test-stats-ula-star.db-msk0.amvera.tech:5432/teststats?sslmode=require
```

Вместо слова `ПАРОЛЬ` - пароль пользователя базы. Он лежит в кабинете Amvera:
проект `test-stats` → **Конфигурация** → «Пароль пользователя», значок глаза
показывает его.

Адрес `test-stats-ula-star.db-msk0.amvera.tech` - внешний домен базы, создан
11.09.2026 в разделе «Домены» проекта `test-stats». Внутренний адрес
`amvera-ula-star-cnpg-test-stats-rw` работает только изнутри Amvera, для
приложения, и снаружи недоступен.

## Что означает каждая цифра

**Прохождений начато** - сколько раз нажали «Начать». Считаются разные номера
прохождений, а не строки в базе: один человек в одной вкладке даёт один номер.

**Дошли до результата** - сколько добрались до текста с типом.

**Доходит до конца** - отношение второго к первому. Главная цифра теста.
Падает - значит тест длинный, скучный или непонятный.

**Где бросают тест** - на каком вопросе люди уходят чаще всего. Считается по
брошенным прохождениям: берём те, где нет события «результат», и смотрим
последний вопрос, на который человек ответил. Если один и тот же номер
всплывает постоянно - с этим вопросом что-то не так.

**Какие типы выпадают** - распределение результатов. Ради него статистика и
затевалась: по подписавшимся распределение видно с перекосом, потому что
подписываются не все. Здесь видно по всем.

**Всего записей** - сколько строк в таблице. Одно полное прохождение даёт
четырнадцать: старт, двенадцать ответов, результат.

## Чего в базе нет

Ни почт, ни имён, ни адресов, ни сведений об устройстве, ни выбранных
вариантов ответов. Только номер вопроса, до которого дошли, и итоговый тип.
Узнать человека по такой строке нельзя - это и было условием, на котором
статистика собирается.

## Запросы по отдельности

Если понадобится спросить базу о чём-то своём, запросы лежат в
`udobnost/scripts/statistika.mjs` - каждый с объяснением перед ним.
